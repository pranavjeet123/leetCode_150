## Quick Cheat Sheet

| Pattern | When to Use |
|---------|-------------|
| **Two Pointers** | Sorted array, palindrome, pair with target sum |
| **Sliding Window** | Subarray/substring with constraint |
| **Binary Search** | Sorted data, minimize/maximize answer |
| **BFS** | Shortest path, level-order, unweighted graph |
| **DFS / Backtracking** | Exhaustive search, generate combinations |
| **Dynamic Programming** | Overlapping subproblems, optimal substructure |
| **Monotonic Stack** | Next greater/smaller element |
| **Union-Find** | Connected components, cycle detection |
| **Heap** | Top-K elements, merge K sorted lists |
| **Trie** | Prefix search, word dictionary |
